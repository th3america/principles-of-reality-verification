## Implementation boundary

The framework is the methodology of behavior. It is not rewritten to imitate
each operating system, application, or agent stack. Apps, tools, integrations,
and other implementations translate the framework's stable behaviors into the
native mechanisms already available in their target systems.

```slangs
stable framework
+ existing AI/system architecture
→ target-native app/tool/integration
→ behavioral tests + receipts
```

Feed the framework to the AI. Let the AI interrogate it, inspect its own target
environment, identify how the behavior can be made real with what already
exists, and expose any gaps instead of pretending the translation is complete.
